# excel-sales-dashboard
Interactive Excel dashboard using Pivot Tables, Slicers, and Charts to analyze sales performance.

This project showcases an interactive Excel dashboard built using **Pivot Tables, Pivot Charts, Slicers, and KPIs**.  
It helps analyze **sales performance, revenue trends, top products, and regional insights**.

---

## 🔧 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas

---

## 📊 Dashboard Features
- Total Sales  
- Monthly Revenue Trend  
- Top-Selling Products  
- Region-wise Performance  
- Interactive Filters (Slicers)

---

## 📁 Files Included
- `Excel_Sales_Dashboard.xlsx` – Interactive dashboard  
- `raw_sales_data.csv` – Dataset used  
- `README.md` – Project documentation

---

## 🎯 Key Insights
- Identify high-performing sales months  
- Track product-level sales contribution  
- Monitor regions driving the highest revenue
